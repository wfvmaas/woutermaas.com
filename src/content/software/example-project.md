# Introduction

This is an example project page that demonstrates how markdown content is rendered using the **ProjectPageLayout** component.

## Features

The layout supports all standard markdown features:

- **Bold text** and *italic text*
- Lists (ordered and unordered)
- Code blocks
- Images
- Links
- And more!

## Code Example

Here's a simple code snippet:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```
